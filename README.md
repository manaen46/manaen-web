# Manaen — version ordinateur

Assistant pro de Franck (génie climatique, froid, plomberie, bâtiment, enseignement).

Ouvrir : https://manaen46.github.io/manaen-web/ puis « Installer » dans Chrome ou Edge.

La clé API, la mémoire et les documents restent dans le navigateur de l'ordinateur : rien n'est stocké sur GitHub.
