Bienvenue, je suis Manaen

Ton assistant pro en génie climatique, plomberie, bâtiment et enseignement. Pour me réveiller, colle ta clé API Claude.

Où trouver ma clé ?
  1. Va sur console.anthropic.com et connecte-toi.
  2. Menu Billing : ajoute un petit crédit (5 € suffisent pour commencer).
  3. Menu API Keys → Create Key, nomme-la « Manaen ».
  4. Copie la clé (elle commence par sk-ant-) et colle-la ici.
